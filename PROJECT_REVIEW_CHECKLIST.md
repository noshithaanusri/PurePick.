# Project Review Checklist

- [ ] `npm install` completes.
- [ ] `npm run dev` starts the React + Vite application.
- [ ] Customer can sign up and log in.
- [ ] Customer can browse products, add to cart and place an order.
- [ ] Customer can view/cancel their own orders.
- [ ] Admin can log in with the demo credentials in README.
- [ ] Admin can view all orders and update order status.
- [ ] Admin can add/delete inventory products.
- [ ] `npm run build` completes successfully.
- [ ] GitHub repository is pushed and Vercel deployment URL is tested.

**Review note:** Local Storage is browser-specific and is intended for the requested academic demo. Do not use the demo credentials or Local Storage authentication for a production store.
